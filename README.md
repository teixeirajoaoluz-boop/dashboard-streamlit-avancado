# 📈 Dashboard de Ações (Streamlit)

Dashboard interativo de ações da B3 construído com Streamlit, yfinance e Plotly.
Compara ativos como ITUB4, PETR4, VALE3, WEGE3 e outros com o Ibovespa (`^BVSP`) desde 2020.

## Como rodar

```bash
pip install -r requirements.txt
streamlit run main.py
```

## Arquivos

- `main.py` — dashboard completo (versão avançada)
- `main_original.py` — versão inicial, mais simples
- `.streamlit/config.toml` — tema escuro personalizado
